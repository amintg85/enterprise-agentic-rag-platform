# Security

Do not commit credentials, API keys, production documents, tokens, or customer data.

## Controls demonstrated
- JWT/RBAC architecture
- Input and upload validation
- Prompt-injection checks
- Tool authorization boundary
- Audit logging
- Secret externalization
- Dependency and CodeQL scanning

For production, integrate an enterprise IdP, KMS, WAF, private networking, malware scanning, centralized immutable audit storage, and organization-specific AI governance.
